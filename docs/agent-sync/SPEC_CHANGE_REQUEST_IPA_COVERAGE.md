## 变更概述

随包词典资产中**所有单词（无空格词条）的美音 `ipa` 与英音 `ipaBr` 两列补齐到全覆盖**：
空缺由确定性 G2P 引擎（espeak-ng）离线批量生成，**既有非空值一律不覆盖**（merge_ipa.py 同口径）。
纯数据资产变更（v8 → v9），运行时代码唯一改动 = `DICT_ASSET_VERSION` 门禁常量同步。

## 背景与现状审计（2026-10-10 实测，详见 AUDIT_REPORT_IPA_COVERAGE.md）

- 触发词 `flayer`：词条完整（释义 EN+CN、例句 v7 生成），但 ECDICT 源库 `phonetic` 空（bnc/frq=0 长尾）
  且 ipa-dict 未收（收了 slayer 没收 flayer）→ 双列空。
- 覆盖面（资产 v8，单词 = text 不含空格，共 449,387 条）：

  - 英音 `ipaBr` 有值 64,307（14.3%），**缺 385,080**；
  - 双全 59,387。
- 短语（387,011 条）英音恒为 0（源只收单词）；美音仅 17,953——**本批不动短语**（见 D3）。
- 运行时回填链路 FR-22 批已建（`needsEnhancementBackfill` 闸门含美音/英音缺失、只补空缺），
  已导入词靠 lookup 自动回填，**零行为代码变更**。

## 技术方案

### D1 填充引擎 = espeak-ng（已装机验证，2026-10-10）

- 引擎：espeak-ng 1.51（GPL-3.0，**构建期工具不入 APK**，资产产物为纯文本音标字符串）。
- **就位方式（已验证）**：MSI（github 代理窗口 3 次重试后落地）→ `msiexec /a` 管理员镜像安装到
  `tools/dict/espeak-ng-a/`（免装系统；7-Zip 直接解包会扁平化目录结构导致 voice 全失联——不可用）；
  另需 UCRT app-local 拷贝（`System32\downlevel\api-ms-win-crt-*.dll` + `ucrtbase.dll` 到 exe 旁，
  Win10 19045 实测必需）。目录 gitignore。
- 双口音实测样本（`-q --ipa -v en-us/en-gb`）：

  | 词 | en-us | en-gb | 口音判据 |
  |---|---|---|---|
  | flayer | `flˈeɪɚ` | `flˈeɪə` | rhotic ɚ/ə ✓ |
  | dance | `dˈæns` | `dˈans` | trap-bath æ/a ✓ |
  | quokka | `kwˈɑːkə` | `kwˈɒkə` | lot ɑː/ɒ ✓ |
  | distributist | `dˈɪstɹɪbjˌuːɾɪst` | `dˈɪstɹɪbjˌuːtɪst` | 闪音 ɾ/t ✓ |
  | octodecillion | `ˌɑːktədɪsˈɪliən` | `ˌɒktədɪsˈɪliən` | 主次重音结构 ✓ |

- **批量通道（已验证）**：stdin 行模式——单词每行喂入，stdout 每词一行、**行数严格守恒**
  （10k 实测 10000→10000、rc=0、零空行）；单进程 10k 词 3.9s → 全量双列 60 万条约 **4 分钟**，
  无需分块续传复杂度（保留行数守恒与空值断言为写库门）。
- 已实测否决的备选：
  - **gruut**（pip 纯 Python）：en-us/en-gb 输出**完全同形**（无口音区分）、重音符置于音节内非标准位
    （flayer → `flˈeɪɚ`）、长词多重重音（octodecillion → `ˈɑktˈɑdɪsˈɪljən`）——质量不达标；
  - **CMUdict + g2p_en**：仅美音（无 en-gb），且引 torch 重依赖；
  - **ollama LLM 生成**：音标错误无法系统性审计（本批底线 = 确定性可复现），否决。

### D2 记法 = espeak 真 IPA 原样入列，不做记法归一化

- 资产音标将三记法并存：ECDICT 类 DJ（`'meikә`，存量 217k）/ ipa-dict 真 IPA（存量 33k+64k）/
  espeak 真 IPA（本批新增 ~60 万）。同屏混排**已有先例并接受**（DUAL_IPA ADR-010）；
  全量记法归一化 = 重标注存量，违背 DUAL_IPA「不重新标注」裁决，不做。
- **espeak 记法两点如实告知（pilot 全表 500 词在 `%TEMP%/enrich_work/ipa_pilot_table.txt` 供人审）**：
  1. 主重音符 `ˈ` 置于音节核（元音）前、onset 之后（`mˈeɪkɚ`），与存量两种记法的音节首标记
     （`'meikә` / `ˈsɫeɪɝ`）位置习惯不同——**不可机器归位**（coda/onset 切分需音节化知识，
     朴素左移会把 confirm 的 kənˈfɜːm 错标成 ˈkənfɜːm），保持原样；
  2. 音符集更丰富（ɹ ɾ ᵻ ɐ ˌ 次重音）——展示层纯文本渲染，无兼容问题。

## 风险与取舍

- [x] 中风险（数据面）——运行时零行为变更，风险集中在数据质量与体量：
  - espeak 对垃圾长尾词（aaj/gcss 等条目本身异常的词）输出合成读音——展示可接受（词条本身是 ECDICT 病理行）；
  - 三记法并存的视觉差异（已接受先例）+ espeak 重音符位惯例（D2 详述）；
  - 跑批 ~4 分钟（stdin 行模式实测折算），崩溃面小；行数守恒/空值断言为写库硬门。
- 质量门：pilot 样本（分层：常用/派生/科学长词/病理词）人审签收后才全量跑；
  全量后抽样 diff + probe 词断言 + 覆盖率单调校验（只增不减、非空值零改动）。
